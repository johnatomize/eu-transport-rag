## What reranking a question costs

From the rerankers' scoring runs on the dev questions, or the test questions where Questions says so. A local run (`runs/rerank-local/`) costs nothing, and its time is its scoring time a passage, on the Mac and without loading the model, times the 20 passages a reranked run reads, since a run that only tops up the cache scores fewer. A hosted run (`runs/rerank/`) is paid, and its time is each request's round trip, averaged. Its cost is what the API counted, at the configured price.
